# Iris v2.0 Development

## Current focus

Iris v2.0 is the development track for the next major release. The v2 branch is intended for testing and iteration before the stable v2.0 release.

### v2.0-dev improvements

- Persistent conversation history across launches
- New Chat control for starting a fresh conversation
- Improved conversational prompt behavior
- Faster compact responses for routine questions
- Existing Qwen3-4B local AI remains the primary model
- Existing Vosk voice pipeline remains in place
- Existing spoken responses remain in place
- Updated animated rainbow orb presentation
- v2.0 version indicator in the interface

## Stability note

This branch is a development build. Features, interface details, and behavior may change before v2.0 is published as a stable release.
