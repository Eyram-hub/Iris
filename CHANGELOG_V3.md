# Iris v3.0 Development

Iris v3.0 is the next major development track. These are planned features for development and testing; they are not all implemented yet.

## Planned v3.0 features

### AI and conversation
- More natural multi-turn conversations
- Better follow-up question understanding
- Improved response formatting
- Smarter routing between fast actions and the main Qwen model
- Better handling of schoolwork, coding, writing, and general questions
- Persistent conversation history with search

### Voice
- Faster wake-word response
- More reliable continuous listening
- Better speech-to-text handling
- Natural spoken responses
- Ability to stop or interrupt speech
- Clear listening, thinking, and speaking states

### Desktop intelligence
- Broader Windows app launching
- File and folder search
- More automation workflows
- Clipboard-aware commands
- System information and diagnostics
- Expandable command and tool architecture

### Interface
- More advanced animated rainbow orb
- Themes and appearance settings
- Improved chat presentation
- Compact and expanded layouts
- System-tray operation
- Startup and background mode

### Reliability and performance
- Faster startup
- Better model-load diagnostics
- Improved error recovery
- Performance statistics
- Cleaner logging
- Safer handling of local data and model files

### Project and distribution
- Clear versioned releases
- Better installation documentation
- Bug-report workflow
- Release notes for each major update
- Continued open-source development

The final v3.0 feature set may change after testing and user feedback.
